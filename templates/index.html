Architecture

How AI TruthLens Works

A transparent look at the dual image & video deep learning pipeline behind synthetic media detection.

01

Media Preprocessing & Sampling

Images are validated and normalized into canonical RGB tensors. Videos are temporally sampled across key intervals using FFmpeg to extract high-fidelity frames for inspection.

02

Vision Transformer Inference

Our Vision Transformer decomposes the visual field into self-attention patches, detecting frequency anomalies, synthetic smoothing, and generative artifacts characteristic of diffusion and generative video models.

03

Temporal & Spatial Verdict

Produces an unambiguous classification: AI or REAL. For videos, an interactive frame sequence reveals exactly which timestamps contain generative synthesis artifacts.

About TruthLens

Empirical Media Forensics for Images & Videos

As diffusion and neural video generators advance, discerning authentic visual recordings from artificial generation requires deep learned perceptual analysis.

AI TruthLens runs real deep learning classification in your environment using Hugging Face Transformers, PyTorch, and FFmpeg. Instead of relying on crude heuristics or expensive external cloud APIs, TruthLens leverages a fine-tuned Vision Transformer architecture that has studied millions of real and synthetic frames.

Ethical Responsibility & Probabilistic AI

Computer vision classifiers identify statistical correlations in pixel distributions. No AI detection model is 100% infallible. AI TruthLens is designed as an analytical decision-support tool, not definitive judicial proof.

Technical Specifications

  • Model Backbone Vision Transformer (ViT)
  • ML Framework PyTorch + HF Transformers
  • Video Engine FFmpeg Frame Extractor
  • Backend Runtime Python 3.11 / Flask
  • Image Formats JPG, JPEG, PNG, WEBP
  • Video Formats MP4, WEBM, MOV, AVI, MKV
  • Max File Size 32 MB
Privacy & Security

Built for Data Privacy

Your media is analyzed ephemerally in-memory and immediately discarded.

Ephemeral Processing

Uploaded images are processed directly in memory. Video frames are extracted to temporary buffers and removed immediately upon classification completion.

No Third-Party Transmission

Your media is never dispatched to third-party proprietary APIs or external cloud logging services.

Self-Contained Model

All neural network layers run locally inside the container environment using fine-tuned open weights.
